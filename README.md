# codexctl — 让第三方中转 API 也能用 Codex 官方原生全部功能

> 用第三方中转 API 省钱，同时保留 ChatGPT 官方登录态——**Codex 手机 App、Mobile 远程控制、插件、额度查询全都能正常用**。单文件、双击出界面、一键切换。

## 这是什么 / 解决什么痛点

**痛点**：很多人用第三方中转 API 跑 Codex（便宜、国内直连、模型全）。但一旦把请求指向中转站，官方登录态就丢了——结果 **Codex 手机 App 用不了、Mobile 远程控制断了、插件和额度查询也废了**。想省钱就得放弃官方原生功能，二选一。

**这个工具让你不用二选一。** 原理是把「登录身份」和「请求去向」解耦：

- 登录态：保持 ChatGPT 官方（手机 App / Mobile / 插件 / 额度全部照常）
- 请求去向：转到你自己的第三方中转站（省钱、直连、模型全）

两头的好处同时拿。它提供两种模式：

- **混合模式（主打）**：官方登录态 + 第三方中转站。**手机 App 等官方原生功能全开，对话请求走中转。**
- **纯官方模式**：完全回到官方，请求走 api.openai.com。随时一键切回。

工具只负责改配置文件并自动备份，不提供账号，也不提供中转站。

## 下载

前往 **[Releases 页面](https://github.com/hua226529-ctrl/codexctl/releases/latest)** 下载最新版的 `codexctl.exe`，一个文件即可。

## 用之前你需要准备

1. 已安装 Codex，且 `~/.codex/` 目录存在（里面有 auth.json、config.toml）。
2. 一个能正常登录的 ChatGPT 官方账号。**混合模式要求你先在 Codex 里完成一次官方登录**，工具不能替你登录。
3. 你自己的中转站地址和密钥（混合模式需要填）。

## 图形界面用法（推荐）

1. **先完全退出 Codex App**（重要，见下方注意事项）。
2. 双击 `codexctl.exe`，弹出窗口。
3. 窗口顶部显示当前模式和配置详情。
4. 切换：
   - **切到纯官方**：直接点蓝色「切到纯官方登录模式」按钮。
   - **切到混合模式**：在「中转站地址」「密钥」框里填好，再点绿色「切到混合模式」按钮。
     - 地址必填（打开时会自动回填当前地址，可直接改）。
     - 密钥留空 = 沿用现有密钥；填了就用新的。
5. 切换完成后会弹窗提示，**重启 Codex App 生效**。

## 命令行用法

```
codexctl status                                   查看当前状态
codexctl switch official                          切到纯官方登录模式
codexctl switch hybrid --base-url URL --token KEY 切到混合模式
codexctl switch hybrid --base-url URL             切到混合模式（沿用现有密钥）
```

## 注意事项

- **切换前务必先完全退出 Codex**。Codex 运行时会持续覆盖配置文件，导致切换被冲掉。图形界面会检测 Codex 是否在运行并提醒你。
- 每次切换都会自动把原配置备份到 `auth.json.codexctl.bak` 和 `config.toml.codexctl.bak`，需要时可手动还原。
- 混合模式把官方登录态和对话内容都经过你的中转站，中转站能看到这些数据。请只用你信任的中转站。

## 系统要求

- 64 位 Windows（Win10 / 11 实测可用，Win7/8 64 位一般也行）。
- 系统自带的 PowerShell（用来弹出界面）。被企业组策略锁死 PowerShell 的机器弹不出界面，可改用命令行版本。

## 常见问题

**双击 exe 没反应 / 界面没出来？**
界面靠系统自带的 PowerShell 拉起，第一次启动可能要等一两秒。若机器有组策略强制限制 PowerShell 脚本执行，可能弹不出来——这种情况下可用命令行版本（见上方命令行用法）。

**杀毒软件报毒？**
这是无签名小程序的常见误报，不是病毒。需要时在杀软里手动信任即可。
